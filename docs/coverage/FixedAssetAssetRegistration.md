## Drift antar-sumber (6)

Tempat PRD berbeda bunyi dengan foundation atau dengan kontrak komponen. Spec tidak menunggu apa pun: aturan stage sudah menetapkan sisi yang diasersi (foundation untuk pola bersama, kontrak komponen untuk mekanik komponen). Daftar ini menunjukkan bagian mana yang berlawanan dan dokumen mana yang perlu diperbaiki.

- Di spec `TC-FA-FAREG-UI-008-draft-dialog-delete`, langkah 92, 93: Drift PRD vs foundation. PRD §7.2 `D-REG-01`: pilihan campuran dibagi dua kelompok bullet dengan pertanyaan konfirmasi untuk kelompok pertama, tombol `[Cancel]` `[Delete]`. foundation `functions/toast-copy.md` Aturan Terkunci #10: bulk dengan outcome campuran memakai `Are you sure you want to continue?` dan tombol `[Continue]`. Diasersi: foundation, karena dialog konfirmasi bulk adalah pola bersama (SB-4).
- Di spec `TC-FA-FAREG-UI-029-dialog-approver-corrections`, langkah 5: Drift PRD vs foundation. PRD `FAREG-LOGIC-07g`: toolbar dialog `Search · Filter · Export`. foundation `prd-conventions.md` §9.1 (Global Table Rules, toolbar): `Search (icon) | Filter | Download`; kontrak wangs-ui `Tooltip#26` dan `DataTable#81`: ExportButton bertooltip dan beraria-label `Download`. Diasersi: foundation, karena tombol unduh toolbar tabel adalah komponen bersama (SB-4).
- Di spec `TC-FA-FAREG-E2E-041-draft-filter`, langkah 4, 129: Drift PRD vs foundation. PRD §9.5 baris Sumber filter Requested By: User aktif dalam scope Group. foundation `prd-conventions.md` §9.8 (Opsi dropdown filter): opsi diisi nilai DISTINCT kolom sumbernya dan cakupannya mengikuti baris tabel yang sedang tampil. Diasersi: foundation, karena Filter Panel adalah pola bersama (SB-4). Aturan bisnis PRD tentang scope Group tidak dihapus: baris tabel sudah dibatasi cakupan Group aktor.
- Di spec `TC-FA-FAREG-E2E-109-asset-label-default-dan-arsip-dep-settings-asset-labeling`, langkah 11, 49: Drift PRD vs kontrak komponen. PRD `FAREG-LOGIC-16d`: Asset Label default "tidak dapat dilepas per aset". Kontrak `MultiSelect#3` dan `MultiSelect#8`: setiap chip punya tombol lepas dan tidak ada chip terkunci. Diasersi: kontrak untuk mekanik chip (tombol lepas ada, sehingga langkah melepas Asset label default dilakukan), PRD untuk aturan bisnis (Asset Label default tetap terpasang pada aset).
- Planner, temuan 10 (beda-foundation): Judul node auto-cancel karena timeout mengikuti foundation (SB-4: pola approval dipakai ulang lintas modul); label `Canceled by system (plan changed)` tetap dari PRD.
