# Eliminasi Step: Admin Console > Hardware Stock

Modul: Hardware Stock  
Sumber: specs/AdminConsole/HardwareStock  
Tanggal: 2026-11-14

## Kriteria

- **A. Persona Distributor atau Partner.** Persona aktif dilacak dari Prerequisites (akun aktor pertama) lalu dari setiap langkah login, logout, atau ganti akun. Langkah yang dijalankan saat persona Distributor atau Partner aktif dikecualikan, termasuk langkah login yang menuju persona tersebut dan logout dari persona tersebut. Langkah yang menuju atau kembali ke Principal dipertahankan. Persona ditentukan dari nama akun, email, atau nama env var password.
- **B. Halaman detail.** Hanya halaman detail User di Admin Console > Settings > User List (termasuk tab dan sub-tab di dalamnya) dan halaman detail Client di Admin Console > Client List. Langkah yang membuka, memverifikasi, atau beroperasi di halaman itu dikecualikan, termasuk aksi yang masuk ke halaman itu (klik Name atau Company Name, menu Detail). Tidak termasuk B: detail User di Global Settings > User atau Fixed Asset > Settings > User, Detail Non-Login User, serta detail lain di Admin Console (Subscription, License, Device SKU, Stock, Role, Group, Plan, Partner, Distributor, dan sebagainya). Langkah login, buka List, dan Search yang mendahului halaman detail dipertahankan.
- **C. Fitur AI.** Tidak ditemukan (tidak ada).
- **D. Menu Approval.** Hanya menu Approval Admin Console (Admin Console > Approvals, sidebar atau halaman) dan langkah yang masuk atau beroperasi di dalamnya (Approve, Reject, Review di Approvals). Tidak termasuk: Approve/Reject lewat API di luar menu, approval di Fixed Asset, teks approval di dialog, serta sub-tab Pending Approvals pada Responsibilities detail User. Rangkaian langkah D lama dipertahankan hanya bila memuat atau didahului langkah yang menyebut Approvals, atau berada di spek bertajuk approval; langkah API dan Pending Approval dikeluarkan.
- **E. Surface mobile atau Android.** Surface mobile atau Android, serta resize viewport desktop (alasan "resize viewport desktop"). Termasuk langkah verifikasi yang hanya ada karena resize itu (gulir horizontal, kolom beku, layout viewport sempit, walkthrough tertutup saat resize).

- TC-AC-ACHS-E2E-243 langkah 1, 4, 7, 9, 13, 16, 18, 20, 30, 32, 36: Aksi lewat sesi API atas nama akun Distributor/Partner sementara UI aktif Principal; dipertahankan karena persona UI = Principal

- TC-AC-ACHS-E2E-285 langkah 81: Aksi lewat sesi API atas nama akun Distributor/Partner sementara UI aktif Principal; dipertahankan karena persona UI = Principal
- Detail User tanpa jalur navigasi eksplisit (mis. "Buka Detail User X > tab System Log", "User Detail > System Log") dianggap Admin Console > Settings > User List dan dihitung B. Konfirmasi bukan Global Settings > User.
