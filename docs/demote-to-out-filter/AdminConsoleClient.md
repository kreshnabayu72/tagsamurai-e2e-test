# Eliminasi Step: Admin Console > Client

Modul: Admin Console > Client  
Sumber: specs/AdminConsole/Client  
Tanggal: 2026-11-14

## Kriteria

- **A. Persona Distributor atau Partner.** Persona aktif dilacak per langkah dari akun di Prerequisites (akun pertama, atau akun di hook before) dan dari langkah login, logout, atau ganti akun. Langkah yang dijalankan saat persona Distributor atau Partner aktif dikecualikan, termasuk langkah login ke persona itu dan logout dari persona itu. Langkah login kembali ke Principal dipertahankan.
- **B. Halaman detail.** Hanya halaman detail User di Admin Console > Settings > User List (termasuk tab dan sub-tab di dalamnya, mis. Tab System Log) dan halaman detail Client di Admin Console > Client List (termasuk tab, sub-tab, header, dialog Edit, dan modal Changelog yang dibuka dari dalamnya). Langkah yang membuka, memverifikasi, atau beroperasi di halaman itu dikecualikan, termasuk aksi yang masuk ke halaman itu (klik Company Name, menu Detail, URL Detail) dan aksi kembali (breadcrumb, Kembali ke List, Back). Tidak termasuk B: detail User di Global Settings > User, detail User di Fixed Asset > Settings > User, Detail Non-Login User, serta detail lain di Admin Console (Subscription, License, Device SKU, Role, Group, Partner, Distributor, dan sebagainya). Langkah login, buka List, dan Search yang mendahului halaman detail dipertahankan.
- **C. Fitur AI.** Tidak ada langkah yang menguji fitur AI (kata kunci AI dicek, nol hasil).
- **D. Menu Approval Admin Console.** Hanya langkah yang masuk ke Admin Console > Approvals (sidebar atau halaman Approvals) atau mengoperasikannya (Approve, Reject, dan tunggu aksinya di Approvals). Tidak termasuk: Approve/Reject lewat API di luar menu, approval di Fixed Asset, teks approval di dialog, serta sub-tab Pending Approvals pada Responsibilities detail User. Langkah yang hanya memicu approval di halaman lain (Submit yang masuk antrean) dipertahankan.
- **E. Surface mobile atau Android, serta resize viewport desktop.** Spek Android dan mobile (024, 065, 228) serta langkah simulator tablet kiosk (246) dikecualikan. Langkah yang mengubah ukuran viewport browser desktop (mis. 023 langkah 25-29) juga dikecualikan sebagai E dengan alasan "resize viewport desktop". Tablet pada Asset Control (data hardware di web) tidak dihitung sebagai surface mobile. Termasuk langkah verifikasi yang hanya ada karena resize itu (gulir horizontal, kolom beku, layout viewport sempit, walkthrough tertutup saat resize).

Catatan: kolom Dependensi bersifat heuristik. Langkah dikecualikan yang mengubah state (Save, Approve, Reject, Suspend, Retry, dan sejenisnya) ditandai, lalu langkah dipertahankan sesudahnya diperiksa. Ketergantungan lintas spek tidak diperiksa.
