# Suite: Admin Console License Allocation Subscription

Suite ini mencakup halaman Allocation > Client Subscription: List Subscriptions dengan tab Current dan History (Search, Filter, Sort, Pagination, Setup Column, Download, preservasi state), Subscription Detail, Guided Tooltip, form `+ Subscription` (varian Add, Renew, Convert) dengan Preview Payment, Activate Trial, Edit, Convert Trial, Cancel Subscription, Cancel Request, Resubmit, job sistem (Scheduled Flip dan Timeout Auto-Cancel), efek Approve dan Reject dari Approvals, Modal Changelog, Modal Subscription Log, pencatatan log di Changelog, Activity Log, System Log, dan Subscription Log, Role Matrix dan scope data per Plan Owner, format tanggal General Settings, sinkronisasi ke modul konsumen, notifikasi in-app, defense-in-depth, state tenant (Client Suspended atau Expired), konkurensi, serta ketahanan terhadap kegagalan server.

`parallel: false` karena spec mengubah atau bergantung pada state global: toggle Require Approval for Allocation dan Require Approval for Trial Activation, Approval Timeout, ceiling Trial (Max Trial Duration, Asset Quota, Concurrent User Quota), harga feature plan, saldo kantong Wallet, format tanggal dan zona waktu General Settings, jam server, status Suspended atau Expired entitas dan Client, capability role, dan flag Guided Tooltip. Spec yang menggeser jam server atau mengubah state global memulihkannya di hook `after`. Setiap spec tetap menyiapkan dan membersihkan datanya sendiri lewat hook dan tidak bergantung pada hasil spec lain.

## Hook suite

- Hook `beforeEach` suite membuka Allocation > Client Subscription pada tab Current; spec yang dimulai dari halaman lain (Approvals, Subscription Detail, Client Detail, Notifikasi) berpindah halaman sebagai langkah pertama. Hook `beforeEach` suite juga menjadi jaring pengaman S-09: mengonfirmasi `beforeunload` dan menutup dialog `Unsaved Changes`; itu bukan pengganti langkah pemulihan form dirty di spec. `## Prerequisites` spec merujuk pernyataan ini dengan satu baris.
- Login akun aktor: hook `before` suite login akun Total Control Principal (Pre-setup #1) sebagai akun default; spec yang memakai akun lain login akun pertama spec itu di hook `before` spec, dan hook `after` mengembalikan sesi ke akun default.
