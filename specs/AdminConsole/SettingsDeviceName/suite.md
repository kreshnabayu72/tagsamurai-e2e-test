# Suite: Admin Console Settings Device Name

Suite ini mencakup halaman Settings > Device > Device Name: List (kolom turunan SKU, chip Brand dan Model/Type, popup +N more, Search, Filter, Sort, Pagination, Setup Column, Download, preservasi state), Category Sidebar (filter rekursif, collapse, preservasi), dialog Detail dengan tabel Usage by Company, Create, Edit, Delete single dan Bulk Delete beserta dialog blok dan konfirmasi, modal Changelog (Search, Filter, Sort, Setup Column, Pagination, Download), Guided Tooltip, tampilan mobile, Role Matrix dan entity gate, pencatatan di Changelog, Activity Log, dan System Log aktor, sinkronisasi ke Device SKU, registri Hardware dan All TAGs, serta master data konsumen, defense-in-depth sisi server, konkurensi dua admin, dan ketahanan terhadap kegagalan server.

`parallel: false` karena spec memakai state global bersama: Selection Limit di Lifecycle Settings > System Limits (diturunkan ke 100 oleh spec Bulk Delete), Date Format, Time Format, dan Timezone General Settings, capability role (pencabutan Delete), nama master Measurement, Category, dan Brand yang di-rename lalu dipulihkan, konfigurasi Setup Column dan state collapsed Category Sidebar per user, flag Guided Tooltip, serta perangkat Android bersama untuk spec mobile. Spec yang mengubah state global memulihkannya di hook `after`. Setiap spec tetap menyiapkan dan membersihkan datanya sendiri lewat hook dan tidak bergantung pada hasil spec lain.

## Hook suite

- Hook `beforeEach` suite membuka Settings > Device > Device Name pada sub-tab Device Name; spec yang dimulai dari halaman lain (akun tanpa menu Device Name, All TAGs, Hardware) berpindah halaman sebagai langkah pertama. Hook `beforeEach` suite juga menjadi jaring pengaman S-09: mengonfirmasi `beforeunload` dan menutup dialog `Unsaved Changes`; itu bukan pengganti langkah pemulihan form dirty di spec. `## Prerequisites` spec merujuk pernyataan ini dengan satu baris.
- Flag Guided Tooltip `guided_tooltip_seen_ac-settings-device`: hook `before` suite mencatat nilai awal flag lalu menyetelnya `seen` (true) untuk setiap akun UI yang dipakai suite, dan hook `after` memulihkan nilai awal. Spec Guided Tooltip memakai akun Pre-setup #28 dan mengatur flag sendiri sesudah hook. Kemampuan membaca dan menyetel flag disediakan tim FE/BE.
- Sesi API aktor: login API (password) untuk akun yang sama dengan sesi UI memakai token yang tidak dihitung sebagai sesi web (bagian 5), sehingga pelaku kedua (Maya Putri, Pre-setup #2) yang hanya memicu perubahan state memakai sesi API. Kemampuan itu disediakan tim BE/FE dan dinyatakan sekali di sini.
- Fixture backend pemulihan state Pre-setup: baris Pre-setup bersama yang terpaksa berubah (Selection Limit, General Settings, capability role, nama master Measurement, Category, dan Brand, unit BYO, SKU) dipulihkan ke keadaan awal oleh fixture backend yang disediakan tim FE/BE di hook `before` dan `after` spec yang mengubahnya dan sebagai langkah penghubung antar blok TC dalam satu spec (S-06, pengecualian 2026-10-30). Efeknya (Last Modified dan entri audit trail) dicatat di `## Prerequisites` spec yang bersangkutan. Data Device Name inti (Pre-setup #16), seed 120 baris (#17), dan nama panjang (#23) bersifat baca-saja untuk spec List dan Changelog; spec yang menulis memakai record milik spec sendiri bersuffix `{runId}`.
- Kemampuan teknis yang disediakan tim FE/BE dan dirujuk spec dengan satu baris: klien HTTP untuk request langsung ke server (spec defense-in-depth), `Spectra.intercept()` untuk respons gagal dan lambat (spec resilience), pembaca berkas CSV dan XLSX hasil unduhan, seed Principal Uji Volume (Pre-setup #25) dan Principal Uji Download Besar (#26), seed unit BYO, SKU, dan tag NFC Jalur A dan Jalur B (Pre-setup #18, #22, #27, #29), simulator driver USB (spec Jalur B Handheld Reader), dan perangkat Android uji untuk spec mobile.
- Preferensi kolom tabel Usage by Company (Setup Column, tersimpan di cache browser): kemampuan "hapus preferensi kolom Usage di browser" disediakan tim FE dan dipanggil di hook `before` dan `after` spec yang mengubah kolom Usage (094, 095, 096); spec yang menyembunyikan kolom tabel List (108, 113 dan sejenisnya) memakai kemampuan yang sama untuk preferensi kolom List; pemulihan tidak memakai `[Reset to Default]`.
- Password akun aktor memakai env var `<APP>_<ROLE>_PASSWORD` (bagian 5 konvensi): semua akun Total Control Principal `AC_TC_PASSWORD`; akun lain memakai nama berkode modul `AC_DN_<ROLE>_PASSWORD` yang sudah terdaftar di `executionConfig.environmentVariables` (`spectra.config.ts`) dan `.env.example`. Email akun Pre-setup #1 sampai #12 dan #28 dirujuk lewat `Fixture.settings-device-name` (belum ada, disediakan tim FE).
