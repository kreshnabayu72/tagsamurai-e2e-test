# Suite: Admin Console Hardware Stock

Suite ini mencakup modul Hardware Stock Admin Console: Stock List dan Stock Detail (Tab Available dan Tab In Use), Add Stock manual (Smart Fixed Reader, BLE Gateway) dan Add Stock Sync (Handheld Reader), Delete Unit, Approvals > Hardware Stock (Tab Active, Tab History, Dialog Detail Approval, Approve dan Reject untuk Register Duplicate dan Activation Collision), Popup Event Log dan Popup Hardware Log, tabel tools enam permukaan (Search, Filter, Sort, Setup Column, Pagination, Download), Role Matrix, scope Distributor dan Principal, Guided Tooltip, format tanggal dan waktu General Settings, pencatatan Activity Log, System Log, dan Hardware Log, dampak lintas modul, state tenant, defense-in-depth, volume besar, dan ketahanan terhadap kegagalan server.

`parallel: false` karena spec mengubah state global bersama: General Settings (format tanggal, waktu, zona waktu), System Limit `register_asset_bulk_limit`, flag Guided Tooltip, preferensi kolom Setup Column di browser, status Suspended atau Expired entitas, toggle Local Registration Distributor, pool Additional Approver, serta pembuatan dan penghapusan SKU dan unit yang mengubah hitungan Stock List dan isi Approvals. Spec yang menghapus data (Delete Unit, hapus baris terakhir, hapus SKU) dan spec yang mengubah baseline tabel (Add Stock, Approve dan Reject, state tenant) dijalankan sesudah spec baca dan spec tabel yang bergantung pada baseline Pre-setup. Setiap spec tetap menyiapkan dan membersihkan datanya sendiri lewat hook dan tidak bergantung pada hasil spec lain.
