# Suite: Admin Console Settings Group

Suite ini mencakup halaman Settings > Group: tabel utama Group List beserta Group Context Header, Sidebar Group Tree, Search, Filter, Sort, Setup Column, Pagination, Download, dan Guided Tooltip; Modal Changelog: Group; popup Total User Detail dan Total Member Detail; Create Group dan Add Subgroup (termasuk Hierarchy Depth Limit), Edit Group, Delete Group single dan Bulk Delete beserta guard member dan last group, Selection Limit; Role Matrix per aktor (Total Control, Default User, Read Only, kombinasi Manage group, Group Manager, entitas Distributor, Partner, dan Client); pencatatan di Changelog, System Log, dan Activity Log serta absennya; sinkronisasi lintas modul (Settings > User, Role & Permission, form Create Distributor/Partner/Client, Wallet, General Settings); defense-in-depth; state tenant (Suspended, Expired, Grace, Archive); konkurensi dua admin; ketahanan terhadap kegagalan server; serta tampilan mobile Android.

`parallel: false` karena spec memakai atau mengubah state global dan data bersama: Hierarchy Depth Limit dan Selection Limit di Lifecycle Settings > System Limits, status entitas uji (Suspended, Expired, Grace, Archive), pohon group entitas uji yang dihapus atau diubah (pemulihan baseline), flag Guided Tooltip, dan perangkat Android bersama. Setiap spec tetap menyiapkan dan membersihkan datanya sendiri lewat hook dan tidak bergantung pada hasil spec lain.

## Hook suite

- Login dan halaman: akun aktor pertama login di hook `before` spec; hook `beforeEach` suite membuka Settings > Group lewat sidebar. `## Prerequisites` spec menulis "Login di hook `before` spec ini; halaman dibuka hook `beforeEach` suite". Spec yang selesai di akun lain memulihkan sesi ke akun default spec di hook `after`. Pengecualian: akun tanpa menu `Group` di sidebar (spec 016 blok Client, spec 018) tidak memakai `beforeEach` itu; spec menuliskan cara membuka halaman atau membuktikan ketiadaan menu di `## Prerequisites`.
- Flag Guided Tooltip halaman Settings > Group: hook `before` suite mencatat nilai awal flag lalu menyetelnya `seen` (true) untuk setiap akun UI yang dipakai suite; hook `after` memulihkan nilai awal. Spec yang menguji Guided Tooltip (012 dan 013) mengatur flag belum `seen` sendiri sesudah hook dan menyebutnya di Prerequisites. Kemampuan membaca dan menyetel flag disediakan tim FE/BE.
- Jaring pengaman form dirty: hook `afterEach` suite mengonfirmasi dialog `beforeunload` dan menutup dialog `Unsaved Changes` yang tersisa. Ini bukan pengganti langkah pemulihan eksplisit di spec (S-09).
- Sesi API aktor: login API (password) untuk akun yang sama dengan sesi UI memakai token yang tidak dihitung sebagai sesi web, sehingga sesi UI tidak diusir. Kemampuan ini disediakan tim BE/FE; `## Prerequisites` spec merujuknya dengan satu baris. Pelaku kedua yang hanya memicu perubahan state memakai sesi API ini.
- Fixture BE: seeding dan pemulihan baseline group tree per entitas uji (Pohon Uji Utama, Distributor Hapus Utama, Satu Group, Dua Group, Tiga Group, Tiga Campur, Pohon Dalam, Seleksi Besar, Race, Pembanding, Suspended, Expired, Grace, Archive, Changelog), penugasan Group Role dan Group Manager, entri seed Changelog Group, status keaktifan entitas, Hierarchy Depth Limit dan Selection Limit per entitas, injeksi kegagalan respons (5xx, Download gagal) dan penahanan respons untuk Saving state, pembacaan state BE yang tak terlihat di UI, serta klien HTTP untuk request langsung ke endpoint Group, disediakan tim FE/BE tanpa endpoint karangan di spec. Kemampuan baca atau seed yang tidak disebut TC, PRD, atau LLD dicatat di "Temuan untuk QA".
- Pemulihan baseline: entitas uji yang ditulis, diubah, atau dihapus spec dipulihkan ke baseline Pre-setup lewat Fixture BE di hook `before` dan `after` spec pemiliknya dan sebagai langkah penghubung antar blok TC (aksi tanpa `Verifikasi`, dicatat satu butir `## Notes`, S-03/S-09). Efek pada Last Updated, Modified By, dan entri audit trail dicatat di `## Prerequisites` spec pemiliknya.
- State global yang dipulihkan di hook `after` spec pemiliknya: Hierarchy Depth Limit entitas Distributor Pohon Dalam (spec 033) dan Distributor Suspended Dalam (spec 098), Selection Limit (spec 047), status entitas uji Suspended/Expired/Grace/Archive (spec 098-099), dan flag Guided Tooltip (spec 012-013).
- Konfigurasi kolom Setup Column yang disimpan spec: hook `after` (dan `before`) spec pemiliknya menghapus preferensi kolom tabel di browser, bukan `[Reset to Default]` (kemampuan disediakan tim FE). Spec yang menyembunyikan atau menyimpan konfigurasi kolom: Group List 050, 054, 058-061, 065, mobile 014, Modal Changelog 074, popup Users 082, popup Members 086.
- Data Pre-setup (Tabel Data Uji Pre-setup TC) dibaca saja oleh spec screening, Search, Filter, Sort, dan popup; aksi tulis dan hapus memakai node milik spec yang di-seed di hook `before` dengan suffix `{runId}-<NNN>` (S-06, S-12), kecuali bila TC menuntut node Pre-setup tertentu (dicatat di `## Prerequisites` spec bersama pemulihannya).
- Penomoran spec: rencana awal 001-105; nomor cadangan yang dipakai penulis (spec dipecah dari spec asal): 106 (TC-32, dari 009), 107 (TC-55 dan 56, dari 014), 108 (TC-67, dari 019), 109 (TC-70, dari 020), 110 (TC-144 dan 145, dari 041), 111 (TC-163 dan 164, dari 046), 112 (TC-232, dari 064), 114 (TC-269, dari 074), 115 (TC-292 dan 293, dari 079), 116 (TC-335 sampai 337, dari 091), 117 (TC-342, 351, dan 352, dari 092).
