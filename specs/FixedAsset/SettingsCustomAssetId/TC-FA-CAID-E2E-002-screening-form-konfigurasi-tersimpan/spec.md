# Screening Form Konfigurasi Tersimpan: Nilai, Tooltip, Baris Initial Company, dan Daftar Segmen

## Prerequisites

- Mode: FE+BE.
- Login di hook `before` spec ini; halaman Fixed Asset > Settings > Asset Master > Custom Asset ID dibuka hook `beforeEach` suite.
- Akun aktor: Total Control Company Alpha (Pre-setup No 1, akun default suite) `totalControl_automated_{namaCompany}@qwertysystem.net`, password `Spectra.env.FA_TC_PASSWORD`. Password tidak ditulis di spec atau fixture.
- Hook suite (`suite.md`): flag Guided Tooltip disetel seen; konfigurasi Company Alpha dipulihkan ke baseline B1 dan aset A1 sampai A5 ke Pre-setup No 11 di `beforeEach` lewat sesi API aktor.
- Data Pre-setup No 10: baseline B1 (Master Switch ON, Separator `/ (Slash)`, segmen tercentang Group Code, Category Code, Asset Name Code, Purchase Date, Asset Increment, tanpa Initial Company) dan baseline B2 (Separator `- (Dash)`, Initial Company `ABC`, Division Code tercentang di atas B1). Nilai dibaca dari `Fixture.customAssetId.<kunci>` (berkas `fixtures/customAssetId.json` belum ada; prasyarat tahap script yang disediakan tim FE/BE). B2 di-seed spec ini sebelum TC-FA-CAID-7 dan B1 dipulihkan spec ini sesudahnya.
- Kemampuan teknis: sesi API Total Control Company Alpha untuk mengganti baseline (disediakan tim FE); intercept respons pembacaan konfigurasi Custom Asset ID yang menahan respons lalu melepasnya (`Spectra.intercept()`; endpoint tidak tertulis di TC, disediakan tim FE). Intercept dipakai hanya untuk mengamati skeleton, bukan kegagalan.
- State global: spec menggeser Master Switch ke OFF pada TC-FA-CAID-8 (menyimpan konfigurasi) dan memulihkannya ke B1 lewat sesi API; hook `after` suite memulihkan ulang bila spec gagal di tengah. Suite berjalan serial (`parallel: false`).

## Test Steps

### TC-FA-CAID-9: Baris Initial Company saat tidak dicentang

1. Verifikasi checkbox `Initial Company` tidak tercentang
2. Verifikasi input teks Initial Company tetap tampil dalam keadaan disabled/dim dengan placeholder `Enter initial company`
3. Verifikasi helper text di bawah input berbunyi `Prefix identifier representing your company entity (up to 5 characters, letters and numbers only). Required when checked.`
4. Verifikasi tidak ada pesan error di bawah input Initial Company

### TC-FA-CAID-10: Delapan baris segmen, checkbox Asset Increment terkunci

5. Verifikasi kedelapan baris segmen masing-masing memiliki drag handle dan checkbox
6. Verifikasi hanya checkbox `Asset Increment` yang disabled dan tercentang
7. Verifikasi di bawah baris `Asset Increment` tampil helper `Uncheck a segment to exclude it from the format. At least 1 segment must stay checked.`

### TC-FA-CAID-7: Konfigurasi tersimpan dimuat apa adanya

8. Ubah konfigurasi Company Alpha ke baseline B2 lewat sesi API aktor hingga konfigurasi tersimpan
9. Muat ulang halaman (F5)
10. Verifikasi Separator menampilkan `- (Dash)`
11. Verifikasi baris `Initial Company` dan `Division Code` tercentang
12. Verifikasi input Initial Company enabled berisi `ABC`
13. Verifikasi Live Preview menampilkan `ABC-JKT-LAP-T490-0000-0926-1`
14. Verifikasi tombol `[Save]` berstatus disabled karena form pristine

### TC-FA-CAID-8: Ikon info (i) di samping switch: tooltip hover dan fokus keyboard pada posisi ON dan OFF

15. Pulihkan konfigurasi Company Alpha ke baseline B1 lewat sesi API aktor hingga konfigurasi tersimpan
16. Muat ulang halaman (F5)
17. Hover ikon (i) di samping label switch
18. Verifikasi tooltip berisi persis `Enable this option to generate Asset IDs using your custom format instead of the default ID generated by the system. Applies immediately to all your existing assets, not just new ones.`
19. Pindahkan kursor keluar, lalu fokuskan ikon (i) dengan keyboard Tab
20. Verifikasi tooltip yang sama tampil saat ikon menerima fokus keyboard
21. Geser switch `Enable Custom Asset ID` ke OFF
22. Klik `[Disable]` pada dialog `Disable Custom Asset ID`
23. Verifikasi toast sukses `Success, Custom Asset ID configuration has been updated.` tampil
24. Verifikasi Master Switch berada pada posisi OFF
25. Hover ikon (i) di samping label switch
26. Verifikasi tooltip tetap tersedia dengan teks yang sama seperti langkah 18
27. Verifikasi tidak ada helper text di bawah switch
28. Pulihkan konfigurasi Company Alpha ke baseline B1 lewat sesi API aktor hingga konfigurasi tersimpan
29. Muat ulang halaman (F5)

### TC-FA-CAID-11: State loading skeleton pada kartu konfigurasi

30. Tahan respons pembacaan konfigurasi lewat intercept, lalu muat ulang tab Custom Asset ID
31. Verifikasi kartu menampilkan skeleton loader selama respons ditahan
32. Lepas tahanan respons
33. Verifikasi skeleton diganti form berisi nilai konfigurasi tersimpan (switch ON dan Separator `/ (Slash)`)

## Notes

- Sumber: `fixed-asset/settings-custom-asset-id/TestCases/tc-settings-custom-asset-id.md`. Subjudul `###` memetakan langkah ke id TC granular.
- Urutan TC di spec: TC-FA-CAID-9 dan 10 (baseline B1 dari hook) lebih dulu, lalu TC-FA-CAID-7 (B2), TC-FA-CAID-8 (B1 dipulihkan; menggeser switch ke OFF), dan TC-FA-CAID-11 terakhir. Alasan: pengelompokan per baseline meminimalkan seeding ulang dan TC-FA-CAID-8 mengubah state sehingga diletakkan sesudah TC pembaca murni (S-10).
- Langkah penghubung (tanpa `Verifikasi`): langkah 8, 9, 15, 16, 28, 29 (ganti baseline lewat sesi API dan muat ulang agar form memuat nilai baseline itu), langkah 17, 19, 25 (hover atau fokus sebagai pemicu tooltip; tooltip diasersi segera sesudahnya), langkah 21 dan 22 (pemicu OFF), dan langkah 32 (lepas tahanan respons). Hasil langkah 22 diasersi langsung (langkah 23 dan 24), sehingga tidak butuh langkah "Tunggu aksi selesai".
- Langkah buka tab TC-FA-CAID-7, 8, 9, 10 dipenuhi hook `beforeEach` suite; langkah muat ulang pada TC-FA-CAID-11 adalah pemicu TC itu sendiri (langkah 30).
- Asersi absence (langkah 4 dan 27) didahului asersi positif atas elemen lain pada surface yang sama (langkah 1 sampai 3 dan langkah 26).
- Tahanan respons pada langkah 30 hanya untuk mengamati skeleton (bukan kelas fault injection); intercept dilepas pada langkah 32.
- Temuan untuk QA:
