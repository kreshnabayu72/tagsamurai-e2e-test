# Screening Halaman Authenticator Verification dan Tampilan Kondisional Use a Different Method

## Prerequisites

- Browser dalam keadaan publik (tanpa sesi aktif / belum login).
- User `Rizky Pratama` (`rizkypratama@qwertysystem.net`) profil NEWDEVE (Authenticator terdaftar).
- User `Nur Hidayati` (`nurhidayati@qwertysystem.net`) profil NEWDEVE (Authenticator terdaftar).
- User `Putri Anggraini` (`putrianggraini@qwertysystem.net`) profil NEWDEVE.
- User `Teguh Wibowo` (`teguhwibowo@qwertysystem.net`) profil NEWDEVE.
- Environment web uji siap menerima akses publik pada rute `/login` dan `/login/otp`.

## Test Steps

### Screening elemen UI Authenticator Verification pasca Login with Password

1. Buka halaman `Auth > Login with Password` (`/login`) di browser
2. Ketik `rizkypratama@qwertysystem.net` pada field Email dan masukkan password valid
3. Centang widget reCAPTCHA dan klik button [Log in]
4. Pada halaman Choose Verification Method, pilih opsi "Authenticator app" lalu klik button [Login]
5. Verifikasi halaman berpindah ke `Auth > MFA > Authenticator Verification`
6. Verifikasi card form tampil terpusat dengan logo TAG Samurai
7. Verifikasi title halaman adalah "Enter authenticator code"
8. Verifikasi subtitle adalah "Enter the 6-digit code generated by your authenticator app"
9. Verifikasi 6 kotak input SegmentedInput tampil kosong dengan kursor aktif di kotak 1
10. Verifikasi button [Login] tampil melebar penuh (variant solid, severity primary)
11. Verifikasi button Text [Use a different method] tampil terpusat di bawah button [Login]

### Visibilitas kondisional pasca Login with OTP (Direct ke Authenticator)

12. Buka halaman `Auth > Login with OTP > Request OTP` (`/login/otp`) di browser
13. Ketik `nurhidayati@qwertysystem.net` pada field Email, centang reCAPTCHA, dan klik [Request OTP]
14. Masukkan kode OTP login yang diterima di email pada halaman Verify OTP
15. Verifikasi halaman berpindah LANGSUNG ke `Auth > MFA > Authenticator Verification` tanpa menampilkan halaman Choose Verification Method
16. Verifikasi button Text [Use a different method] TIDAK tampil (Hidden) pada halaman ini karena faktor-1 adalah OTP

### State fokus slot dan penolakan auto-submit saat digit ke-6 terisi

17. Kembali ke halaman Authenticator Verification untuk user `putrianggraini@qwertysystem.net`
18. Verifikasi kotak 1 berstatus Focus (border severity primary)
19. Ketik berturut-turut digit `1`, `2`, `3`, `4`, `5`, `6`
20. Verifikasi setiap kotak yang terisi angka berstatus Filled
21. Verifikasi setelah kotak ke-6 terisi angka `6`, form TIDAK melakukan auto-submit
22. Verifikasi halaman tetap berada di Authenticator Verification dan button [Login] tetap menunggu tindakan klik pengguna

### Navigasi tombol [Use a different method] dan Accessibility Tab

23. Klik button Text [Use a different method]
24. Verifikasi halaman kembali ke `Auth > MFA > Choose Verification Method`
25. Verifikasi opsi pilihan kembali ke status default (tidak ada opsi terpilih dan button [Login] disabled)
26. Buka kembali halaman Authenticator Verification untuk user `teguhwibowo@qwertysystem.net`
27. Tekan tombol Tab berulang kali dari awal form
28. Verifikasi urutan fokus berpindah secara tertib: kotak 1 → kotak 2 → kotak 3 → kotak 4 → kotak 5 → kotak 6 → button [Login] → button Text [Use a different method]

## Notes

- Sesuai `AUTHMFA-LOGIC-03b`, jika faktor-1 adalah OTP, MFA langsung mengarahkan ke Authenticator tanpa opsi "Use a different method".
- Form Authenticator Verification tidak menerapkan auto-submit pada digit ke-6 (berbeda dari alur OTP email).
